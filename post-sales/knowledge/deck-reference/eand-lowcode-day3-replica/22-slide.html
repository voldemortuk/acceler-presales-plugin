Retrieval Augmented Generation (RAG)
Components of RAG:
 
Retriever
1.  Fetches relevant chunks of text from a knowledge base (like a document store, vector DB, or search engine) based on the user query.
2.  Uses methods like dense retrieval (e.g., using embeddings) or sparse retrieval (e.g., BM25).
 
Generator
3.  Takes the original user query plus the retrieved documents.
4.  Generates a response based on that combined context.
5.  Typically powered by an LLM like GPT, LLaMA, etc.
